# 🏏 IPL Analysis Dashboard (2008-2026)

An interactive Power BI dashboard analyzing 18+ years of IPL data to uncover team performance, player stats, and seasonal trends.

## 📌 Project Overview

| Detail | Info |
|--------|------|
| Tool | Power BI Desktop |
| Dataset | IPL Matches & Ball-by-Ball Data |
| Domain | Sports Analytics |
| Type | Exploratory Data Analysis (EDA) |
| Seasons | 2008 - 2026 |

---

## ✨ Key Features
- 🏆 Season-wise Champions & Runner-up with Team Logos
- 🟠 Orange Cap & 🟣 Purple Cap Holder Stats
- 4️⃣ Top Fours & 6️⃣ Top Sixes Player Tracking
- 📋 Points Table with Team Logos
- 📊 Centuries & Half Centuries Analysis
- 🗓️ Interactive Season Filter (2008–2026)
- 🏟️ Total Matches, Teams & Venues

---

## 🧹 Data Preparation Steps
- Merged multiple CSV files in Power BI
- Created relationships between tables
- Built 15+ custom DAX measures
- Added team logos via image URLs
- Applied season-wise dynamic filtering

---

## 🚀 How to Use
1. Clone this repository
2. Open `.pbix` file in Power BI Desktop
3. Use Season slicer to explore year-wise insights
4. Hover over visuals for detailed tooltips
